# GitHub publishing

A public GitHub repository is an assignment requirement. The project is already a Git repository with incremental milestone commits, but a public remote cannot be created or authenticated from this build environment.

## Recommended repository name
`Smart-Pantry-Manager-MAD700`

## Publish from a machine with the student GitHub account connected

```bash
git remote add origin https://github.com/YOUR_USERNAME/Smart-Pantry-Manager-MAD700.git
git branch -M main
git push -u origin main
```

Then verify the public repository contains the complete source and README. Copy the real public URL into the report before submission.

Do not claim that a public repository exists until the push has completed successfully.
